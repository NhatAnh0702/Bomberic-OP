# Assets

Place game graphics and future media in this folder.

Recommended sprite layout:

- `asset/player/{shirt,necklace,face,eyes,mouth,glasses,hat}/<name>.png`
- `asset/enemy/neutral/{face,eyes,mouth}/<name>.png`
- `asset/enemy/hostile/{face,eyes,mouth}/<name>.png`
- `asset/bomb/{body,fuse}/<name>.png`

Every sprite layer should be a transparent 64 x 64 PNG.
